# MLLANG RFCs

This directory holds RFC proposals for spec changes.

## How to propose

1. Fork repo
2. Copy `../spec/RFC_TEMPLATE.md` to `rfc/<short-slug>.md`
3. Fill in
4. Open PR
5. Discussion happens on the PR

Filename convention: `<NNNN>-<short-slug>.md` where `NNNN` is auto-assigned by maintainer at merge time.
